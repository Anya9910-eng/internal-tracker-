# ANEON — CRM обліку тендерів

Проста самохостингова CRM для ведення тендерів: дошка зі стадіями, картка
тендера з усіма реквізитами, спільний доступ для команди та миттєва
синхронізація між усіма, хто працює одночасно. Це звичайний сервер на
Node + SQLite — без зовнішніх сервісів і API-ключів.

## Що відстежуємо (на кожен тендер)

- **Найменування покупця**
- **Найменування товару** і **Пакування**
- **Строки поставки**
- **Специфікація**
- **Договір**: є / немає, підписаний / не підписаний
- **Реквізити**: для відправки **зразка**, **замовлення** та **документів**
- Нотатки

Тендери рухаються по **стадіях** (колонки дошки) — стадії можна додавати,
перейменовувати, пересувати та видаляти. Картки перетягуються між стадіями.

## Можливості

- **Акаунти** — реєстрація та вхід за email + пароль (хеш scrypt), сесійні cookie.
- **Один спільний простір** — усі бачать ту саму дошку тендерів.
- **Жива синхронізація** — зміни миттєво з’являються в усіх через Server-Sent Events.
- **Зміна паролю** у профілі; **адмін** (перший зареєстрований користувач) може
  скинути пароль колеги на тимчасовий, без email.
- **Пошук** за покупцем або товаром.

## Запуск

Потрібен **Node.js 18+**.

```bash
npm install
npm start
# → http://localhost:3000
```

### Налаштування (необов’язково)

| Змінна       | За замовч.   | Призначення |
|--------------|--------------|-------------|
| `PORT`       | `3000`       | Порт сервера. |
| `DB_PATH`    | `./data.db`  | Де зберігати файл бази SQLite. |
| `NODE_ENV`   | —            | `production` за HTTPS, щоб cookie були `Secure`. |

Файл `data.db` створюється автоматично при першому запуску та наповнюється
кількома прикладами тендерів.

## Розгортання на VPS (коротко)

```bash
npm install -g pm2
NODE_ENV=production PORT=3000 pm2 start server.js --name crew-board
pm2 save && pm2 startup
```

Попереду — зворотний проксі для HTTPS (Caddy або Nginx).

## Структура

```
server.js          Express: REST API + SSE + статика
db.js              Схема SQLite, перший сид
auth.js            Хешування паролів + сесії
public/index.html  Фронтенд (екран входу + дошка тендерів)
```
